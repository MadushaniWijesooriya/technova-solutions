# TechNova Solutions

Professional IT Company Business Website built with React.js, Vite, Tailwind CSS, and Lucide React icons.

## Company
**TechNova Solutions** — Building Digital Solutions for a Smarter Future

## Features
- Fully responsive design (mobile, tablet, desktop)
- Sticky navbar with scroll effect and mobile menu
- Hero, Stats (animated counters), About, Services, Why Choose Us
- Solutions by industry, Technologies, Featured Projects
- Process timeline, Testimonials (demo), CTA, Contact form
- Professional footer

## Getting Started

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually http://localhost:5173).

## Build for Production

```bash
npm run build
npm run preview
```

## Tech Stack
- React 19
- Vite
- Tailwind CSS v4
- Lucide React / React Icons
